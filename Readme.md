\# STRATA





\## Overview





STRATA is a web-based composite combination testing application developed as a group project.





\## Features





\- Has a Database of 52 Composites

\- Provides all technical values for the combination including the limitation and percentage of composition 

\- Multiple (i.e. more than 2) compositions can be performed for a single output

\- Powered with Chatbot
